# FORMA Mebel

Демонстрационный многостраничный сайт вымышленной мебельной студии для Казахстана. Проект работает как React SPA с hash routing и двумя языковыми версиями.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка и локальная проверка:

```bash
npm run check
npm run verify:routes
npm run build
npm run preview
```

## GitHub Pages

Vite настроен на базовый путь `/forma-mebel/`, а маршруты используют hash routing. Содержимое папки `dist` можно опубликовать через GitHub Pages или GitHub Actions. Если имя репозитория изменится, обновите `base` в `vite.config.ts`.

## Где редактировать

- Контакты и будущий способ отправки формы: `src/config.ts`.
- Проекты и их переводы: `src/data.ts`.
- Демонстрационные суммы и состав примеров: `src/pricing.ts`.
- Общие тексты интерфейса: `src/i18n.ts`.
- Страницы и секции: `src/App.tsx`.
- Стили и адаптивность: `src/styles.css`.
- Оптимизированные изображения для публикации: `static/images/`. Исходные PNG и описание промптов: `public/images/`.

Форма намеренно работает только локально: валидирует поля, показывает резюме и позволяет скопировать его, но не отправляет персональные данные. Изображения созданы для этой демонстрационной работы с помощью встроенного генератора OpenAI; проекты являются визуальными концепциями, а не реализованными заказами.

## Языки и шрифт

Интерфейс использует единый словарь `ru/kk`, а язык хранится в hash-маршруте. Стек системных шрифтов начинается с Segoe UI и не требует внешней сетевой загрузки; семейство содержит кириллицу и казахские глифы. Контрольная строка: `Ә Ғ Қ Ң Ө Ұ Ү Һ І / ә ғ қ ң ө ұ ү һ і`.
