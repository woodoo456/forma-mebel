# FORMA Mebel image set

These ten original concept images were generated with the built-in OpenAI image generator for this demonstration site on 2026-09-13. They are illustrative; they do not depict completed client projects.

Shared direction: photorealistic architectural interior photography, believable buildable cabinetry geometry, soft natural or architectural light, warm milk/oak/graphite/warm-grey/restrained-olive palette, no people, text, logos or watermarks.

- `hero-forma`: wide open-plan apartment; warm-grey kitchen and oak wall cabinetry; negative space for web copy.
- `project-kitchen-linear`: bright one-wall kitchen; oak tall units, ivory lower fronts and pale quartz.
- `project-kitchen-graphite`: graphite kitchen with island and an oak-lined niche.
- `project-kitchen-corner`: compact L-shaped kitchen with muted olive lower fronts and terrazzo.
- `project-wardrobe-hall`: full-height entrance wardrobe with an oak bench niche.
- `project-wardrobe-bedroom`: milk-coloured grooved wardrobe wall with oak handles.
- `project-wardrobe-open`: taupe wardrobe with an open oak side section and olive backing.
- `project-closet-compact`: compact two-sided walk-in closet in light oak.
- `project-closet-u`: symmetrical U-shaped walk-in wardrobe in smoked oak.
- `project-closet-glass`: dark-oak walk-in wardrobe with framed glass sections.

The source PNG files are retained alongside the optimized web variants only during local preparation and should not be published when WebP variants are present.
